Mijn projecten

Hier staan projecten die ik tijdens mijn opleiding heb gemaakt.

Autohome

Autohome was mijn eerste project tijdens Software Engineering. Met mijn projectgroep heb ik een simpele home-assistant-fork gemaakt op een Raspberry Pi.

Een lichtsensor leest de lichtniveaus. Daarna kunnen de lichten automatisch aan of uit gaan.

Gebruikte technieken

  • Python
  • Raspberry Pi
  • Lichtsensor

Digitale veilingsklok

De digitale veilingsklok is een project dat ik heb gemaakt tijdens dezelfde module als nu, multilayer webdevelopment. Het is een webapplicatie die een veilingsklok simuleert. De klok telt af en toont de resterende tijd. Als de tijd op is, wordt de veiling gesloten en kan er niet meer geboden worden.

Gebruikte technieken

  • Heel klein beetje docker
  • C#
  • React
